Privacy Policy

The Fish Cutting Zone Uploader · Effective 10 November 2026

The Fish Cutting Zone Uploader ("the tool") is a private tool used only by the owner of the YouTube channel The Fish Cutting Zone to publish that channel's own videos. It is not offered to the public. This policy explains what Google user data the tool accesses and how it is handled.

Data the tool accesses

When the channel owner signs in with Google, the tool requests only these permissions:

  • YouTube upload (youtube.upload) — to upload videos to the owner's own channel.
  • YouTube read-only (youtube.readonly) — to read the owner's own channel name and video statistics.
  • YouTube Analytics read-only (yt-analytics.readonly) — to read the owner's own channel performance (views, watch time).

The tool does not access email, contacts, files or any other Google data, and never accesses any other person's account.

How the data is used

  • To upload the channel's videos with their titles, descriptions and scheduled publish times.
  • To read the channel's own view statistics so the owner can see which videos perform best.

What is stored

The tool stores one OAuth refresh token, encrypted, in Google Cloud Secret Manager, so it can upload on a daily schedule. Channel statistics may be kept as simple records (video ID, view counts) for the owner's own analysis. No other personal data is stored.

Sharing

No data is sold, shared with or transferred to any third party, and none is used for advertising.

Google API Services

The tool uses YouTube API Services. By using it you are agreeing to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions or via Google security settings. On revocation, or on request to the contact below, the stored token is deleted.
